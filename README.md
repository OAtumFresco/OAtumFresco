# Rui Andrade

**Cape Verdean software developer. Creator of Spadinha.**

[Português](README.pt.md) · [RA Tecnologias](https://ratecnologias.cv/) · [LinkedIn](https://www.linkedin.com/in/ruibarrosandrade/)

I build games, web applications and software for everyday work in Cabo Verde. My projects span a card game played with friends, clinical software, and tools that make local information easier to access.

My work includes **RA Tecnologias**, **Atum Fresku**, **Kura** and **Fresku Games**. This profile brings together a selection of those products and the engineering behind them.

## Start with Spadinha

[![Spadinha — the Cape Verdean card game](https://raw.githubusercontent.com/OAtumFresco/spadinha-showcase/main/assets/spadinha.jpg)](https://spadinha.cv/en)

I created **Spadinha** to bring the Cape Verdean card game to mobile. Play solo or create an online room with friends, with a 3D table and characters drawn from Cape Verdean storytelling.
