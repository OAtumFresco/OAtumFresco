# Rui Andrade

**Developer cabo-verdiano. Criador do Spadinha.**

[English](README.md) · [RA Tecnologias](https://ratecnologias.cv/) · [LinkedIn](https://www.linkedin.com/in/ruibarrosandrade/)

Desenvolvo jogos, aplicações web e software para o dia a dia em Cabo Verde. Os meus projetos vão de um jogo de cartas entre amigos a software clínico e ferramentas que tornam a informação do país mais acessível.

O meu trabalho inclui a **RA Tecnologias**, a **Atum Fresku**, a **Kura** e a **Fresku Games**. Este perfil reúne uma seleção desses produtos e da tecnologia que os suporta.
